CSS clip-path properti dan fungsi circle()

Properti clip-path memungkinkan anda untuk memotong/clip elemen menggunakan bentuk tertentu. Fungsi circle() digunakan untuk membuat bentuk lingkaran. Anda dapat menentukan radius lingkaran dan posisi pusatnya. Contoh penggunaan:

contoh

klip gambar ke lingkaran dengan radius 50% dan pusat di tengah gambar.

circle 50%

circle 50% at right

CSS shape-outside dan circle()

Properti shape-outside digunakan untuk menentukan bentuk di luar elemen yang akan memengaruhi alur teks. Fungsi circle() dapat digunakan bersama dengan shape-outside untuk membuat bentuk lingkaran.

CSS clip-path dan ellipse()

Properti clip-path memungkinkan anda untuk memotong/clip elemen menggunakan bentuk tertentu. Fungsi ellipse() digunakan untuk membuat bentuk elips. Anda dapat menentukan radius horizontal dan vertikal serta posisi pusatnya.

contoh

clip gambar ke bentuk ellipse dengan radius 50% x dan 35% y:

CSS shape-outside dan ellipse()

Properti shape-outside digunakan untuk menentukan bentuk di luar elemen yang akan memengaruhi alur teks. Fungsi ellipse() dapat digunakan bersama dengan shape-outside untuk membuat bentuk elips.
